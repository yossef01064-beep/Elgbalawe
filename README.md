# Fatateer

تطبيق Android محلي لإدارة مخزون محل الإلكترونيات، يعمل بدون إنترنت ويحفظ
الأصناف والكميات داخل قاعدة بيانات Room على الجهاز.

## ما تم تنفيذه

- واجهة Jetpack Compose باتجاه RTL وMaterial 3.
- تبويبات الرئيسية وقطع الغيار والبيع.
- تصنيفات قطع الغيار والمبيعات المذكورة أدناه.
- تصنيفات الريموتات HD وSD وتلفزيون، مع الأنواع/الماركات التابعة لها.
- إضافة وتعديل وحذف الأصناف.
- زيادة ونقص الكمية مع منع النزول تحت الصفر.
- حد طلب لكل صنف مع تنبيه للأصناف الناقصة.
- بحث في الاسم والملاحظات والقسم والنوع والماركة.
- حفظ تلقائي محلي عبر Room، وتفضيل الوضع الفاتح/الداكن محفوظ على الجهاز.

## البناء من Android Studio

افتح مجلد `Fatateer` نفسه في Android Studio وانتظر مزامنة Gradle، ثم شغّل
مهمة `app > Tasks > build > assembleDebug` أو التطبيق مباشرة على جهاز/محاكي.
المشروع يستخدم Java 17 وcompileSdk 35، ويحتوي على Gradle Wrapper.

## أقسام رئيسية
قطع غيار: IC الصوت، IC TV، المكثفات، الدوائر الكاملة، IC فرتكال، قطع سماعات

مبيعات:
- ريموتات (قسم واحد مقسوم من جوه: HD / SD / تلفزيون)
- رسيفرات
- تلفزيونات (+ ماركة)
- عدسات دش (TIMER / L/M)
- كابلات (مع بعض)
- كابلات، أدابتر 12V، لفات سلاك دش، أطباق دش، فلانشات، إكسسوار دش
- بطاريات قلم 1.5V

## ريموتات من جوه
- HD → TIMER · L/M · GOTE · EPG
- SD → صيني صف واحد · بدون صف · 2 صف · تورمان · STRONG · USTRA
- تلفزيون → توشيبا · باناسونيك · جولدي · صيني
